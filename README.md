# B4B Frontend

B4B, birden fazla firmanın aynı sistem üzerinden ürün, sepet ve sipariş işlemlerini gerçekleştirebildiği çok kiracılı (Multi-Tenant) bir B2B e-ticaret uygulamasıdır.

Bu repository projenin frontend uygulamasını içermektedir.

## 🚀 Özellikler

- 🔐 Kullanıcı giriş ve çıkış işlemleri
- 🏢 Multi-Tenant firma yapısı
- 📦 Ürün listeleme
- 🔎 Ürün arama
- ➕ Ürün ekleme
- ✏️ Ürün güncelleme
- 🗑️ Ürün silme
- 🛒 Sepete ürün ekleme
- 🔢 Sepet miktarı güncelleme
- 📊 Stok kontrolü
- 📋 Sipariş oluşturma
- 👤 Kullanıcı bazlı işlemler
- 📱 Responsive arayüz

## 🛠️ Kullanılan Teknolojiler

- Next.js
- React
- TypeScript
- Material UI
- Redux Toolkit
- Axios
- JavaScript / TypeScript
- ESLint
